# RAW: Sales POC Playbook Framework
3-4 SMART success criteria set jointly with prospect upfront. 3 opening questions: why are we doing this / what does success look like / who's involved.
4 phases: kickoff+alignment (roles, lock success metrics) -> admin setup (technical config, data migration) -> execution+monitoring (review, unblock) -> evaluation+decision (present vs. criteria).
POC agreement components: executive summary, stakeholder list (sales/eng/product/procurement/legal/security both sides), success criteria, milestones w/ dates+owners, solution overview.
Failure modes: lack of structure (dies in email threads), poor communication/ownership, inadequate resourcing, misaligned success definition.
