# RAW: Orum Platform Integrations page

- Integrates with: Apollo, Gong, HubSpot, Outreach, Salesforce, Salesloft
- Salesforce: bi-directional data sync + report-pulling for dial lists ("connect in minutes")
- Outreach/Salesloft: syncs call activity + surfaces prospect details during live calls; positioned as workflow/call-efficiency partnership, not deep field-level docs published publicly
- Gong: auto-logs call outcomes and recordings
- Note: public page lacks granular field/API documentation - treat as marketing-level source, lower confidence for implementation detail
