# Business Development

## Skill Tree
- Partnership frameworks
- Deal/retainer structuring (Audit -> Pipeline Engine -> RevOps Sprint ladder)
- Proposal & SOW drafting
- Contract review basics (non-compete, IP ownership)

## Prompt Templates
```
Draft a one-page SOW for a [service tier] engagement: scope, deliverables,
timeline, price (CAD), and success criteria. Client context: [stage,
headcount, current stack].
```

## Execution Checklist — Client Onboarding (Audit -> Retainer path)
- [ ] Audit delivered and reviewed with client
- [ ] Upsell conversation scheduled separately from audit delivery
- [ ] SOW drafted for next tier if client converts
- [ ] Contract reviewed for scope creep / IP ownership clauses
- [ ] Kickoff call scheduled with clear success criteria
