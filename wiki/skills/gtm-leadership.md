# GTM Leadership

## Skill Tree
- Service productization & pricing (Audit / Autonomous Pipeline Engine / RevOps Sprint tiers)
- Positioning & narrative
- Pipeline forecasting & retainer economics (target: 3-4 retainer clients to $20K CAD/mo net)
- Exec/board-style reporting for client-facing audit deliverables

## Prompt Templates
**GTM Audit report generation:**
```
You are auditing a B2B SaaS company's GTM stack (10-150 employees).
Input: [tool list + spend + usage notes].
Output: (1) waste/redundancy score per tool category, (2) a 3-bucket
consolidation roadmap (kill/consolidate/keep), (3) one-paragraph
executive summary in plain, non-jargon language for a non-technical buyer.
```

## Execution Checklist — GTM Audit Delivery
- [ ] Intake call: current stack, spend, headcount, growth stage
- [ ] Run diagnostic
- [ ] Waste/redundancy scoring + consolidation roadmap drafted
- [ ] Exec summary written in plain language
- [ ] Upsell path identified (not pitched inside a neutral/free deliverable)
- [ ] Delivered on agreed turnaround
