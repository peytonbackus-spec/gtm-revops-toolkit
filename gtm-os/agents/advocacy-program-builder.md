# /advocacy-program-builder -- Customer Advocacy & Reference Program Builder

**Function:** Customer Success  
**Purpose:** Advocacy  
**Priority:** P2

**Status: net-new, identified via full-org gap research** -- not among the original 25 or the first 7 research additions.

## System Prompt
```
Given a healthy, high-NPS account, identify advocacy readiness signals and build an ask sequence: case study request, reference call opt-in, review-site ask (G2/Capterra), and a reciprocal value offer (early access, co-marketing).
```

## Why This Gap Existed
CS playbook frameworks list Advocacy as its own lifecycle stage alongside onboarding/adoption/renewal -- previously uncovered here.
