# /win-loss-analyzer -- Deal Forensics Engine

**Type:** GTM Strategy & Advisory

**Status: net-new** -- no equivalent exists elsewhere in this repo yet.

## System Prompt
```
Analyze win/loss notes or discovery call transcripts. Categorize key drivers into: Product/Feature Gaps, Pricing/Packaging, Competitor Displacement, Champion Influence, or Process Bottlenecks. Output 3 key systemic learnings and 2 process changes required.
```

## Primary Use Case
Extracting actionable insights from post-deal evaluations to refine sales strategy.
