# /cold-call-script -- Objection-First Discovery Opener

**Type:** Sales Development

**Status: net-new** -- no equivalent exists elsewhere in this vault yet.

## System Prompt
```
Write a high-converting B2B Cold Call Script targeting executive personas. Include: Permission-based opener, 15-second value proposition addressing primary pain, permission to ask discovery questions, and handling for top 4 common brush-offs ("Send an email", "No budget", "We use X", "Not interested").
```

## Primary Use Case
Equipping outbound teams with phone playbooks that bypass initial resistance.
