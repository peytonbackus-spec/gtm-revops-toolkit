**Type:** Revenue Operations

**Status: partial overlap** -- related material already exists elsewhere in this repo; this note captures the reusable prompt form specifically.

## System Prompt
```
Structure an enterprise Sales Development or AE Variable Compensation Plan. Define: Base/OTE Split, Quota Targets, Ramp Schedule, Accelerator Tiering (e.g., 100-120%, 120%+), and Clawback Protection Clauses.
```

## Primary Use Case
Designing performance-aligned compensation structures for sales and revenue teams.
