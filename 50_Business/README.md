# Business Planning

This folder contains the complete business strategy, go-to-market plan,
financial model, execution roadmap, and outreach system for the
Autonomous AI GTM Consulting firm built on top of this toolkit.

## Structure

| Folder | Contents |
|--------|----------|
| `01_Strategy/` | Business overview, niche, positioning, differentiation |
| `02_Services/` | Productized service offers, pricing, scope definitions |
| `03_GTM/` | Go-to-market strategy, channels, content plan |
| `04_Financials/` | Revenue model, worst-case scenarios, survival number |
| `05_Execution/` | 90-day accelerated plan, daily system, weekly rhythm |
| `06_Outreach/` | Prospect identification, lead sources, outreach templates |
| `07_Legal/` | Ontario registration, contracts, GST/HST, insurance |
| `08_Advisor/` | Peer review brief for founder feedback sessions |

## Version history

| Version | Focus |
