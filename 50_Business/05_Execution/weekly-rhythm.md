# Weekly Rhythm

Two full rest days per week are non-negotiable. Scheduled rest prevents
the burnout that kills solo consulting businesses in month 4.

## Daily schedule

| Day | Morning (3–4 hrs) | Afternoon (3–4 hrs) | Evening |
|-----|-------------------|---------------------|---------|
| Monday | Signal scan (BetaKit, TechCrunch, LinkedIn). Research 10 prospects. Add to HubSpot. | Send 20 outreach messages. Reply management. Book calls. | LinkedIn post or content draft |
| Tuesday | Discovery calls (block 9am–2pm) | Proposal writing (same day as call) | Rest |
| Wednesday | Client delivery | Client delivery | Outreach follow-ups if behind |
| Thursday | Discovery calls or delivery | 20 cold messages | Build/iterate one automation |
| Friday | Client delivery. Weekly pipeline review (30 min). | Write one piece of content | Full stop |
| Saturday | **Full rest. No email. No LinkedIn.** | | |
| Sunday | Light planning (30 min max) | Rest | Rest |

## Weekly pipeline review (every Friday, 30 min)

Open HubSpot. Count:
- Messages sent this week
- Reply rate (target: 5%+)
- Discovery calls booked (target: 3+/week)
- Proposals out (target: 2+/week)
- Active pipeline value (target: 3x monthly revenue goal)

If reply rate drops below 5%: change the template.
If calls aren't booking: change the CTA.
If proposals aren't closing: diagnose before sending more.

## The one number that matters most

**Discovery calls booked per week.**
- Target: 3+/week
- Below 2: outreach volume or message quality problem
- Fix before end of week, not next week
