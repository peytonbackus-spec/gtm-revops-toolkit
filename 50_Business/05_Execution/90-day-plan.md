# 90-Day Accelerated Execution Plan (Worst-Case Version)

Assumes: warm network produces 1 client in weeks 2–3, cold outreach
takes 6–8 weeks to close anything, 1 deal slips per month. Still
reaches $10–15K/mo by day 90.

---

## Pre-Day 1 (non-negotiables before anything else)

- [ ] Calculate exact runway (savings ÷ monthly expenses + hidden costs)
- [ ] Read severance agreement — find any non-solicitation clauses
- [ ] Purchase private health/dental insurance ($80–250 CAD/mo)
- [ ] Message 10 trusted professional contacts directly (not a broadcast)

**GATE: Do not proceed until runway is calculated.**

---

## Phase 1 — Days 1–14: Infrastructure and warm outreach only

**Goal:** Business registered, LinkedIn live, 1 discovery call booked
from warm network. Zero cold outreach this phase.

### Days 1–3: Structure

- [ ] Choose your wedge strategy (see `01_Strategy/differentiation.md`)
- [ ] Register sole proprietorship at ontario.ca/businessregistry ($60)
- [ ] Open business bank account (separate from personal, same day)
- [ ] Buy domain (Cloudflare ~$12 CAD/yr) + Google Workspace (~$8/mo)
- [ ] Rewrite LinkedIn headline to reflect chosen wedge
- [ ] Define 3 offers in writing (see `02_Services/offers.md`)
- [ ] Build one-page PDF services overview in Canva
- [ ] Draft consulting agreement (see `07_Legal/contract-template.md`)

### Days 4–7: Warm network saturation

- [ ] Send 30+ personalised DMs to every professional contact
- [ ] Publish LinkedIn pivot post (authentic, specific, clear CTA)
- [ ] Set up HubSpot free CRM (5 pipeline stages, all contacts loaded)
- [ ] Set up Calendly — add link to LinkedIn profile immediately

### Days 8–14: First discovery calls

- [ ] Run every discovery call booked from warm outreach
- [ ] Send proposals within 24 hours of each call
- [ ] Build delivery automations (weekly report, CRM check, sequence summary)
- [ ] Start building website (Webflow or Framer) — aim live by Day 21

**GATE: If zero discovery calls by Day 14, rewrite the outreach message
and send to 20 more people before starting cold outreach.**

---

## Phase 2 — Days 15–45: First revenue + cold outreach begins

**Goal:** First paid engagement. Cold outreach machine running.
$2,500–5,500 CAD received.

- [ ] Day 15: First client signed (50% upfront before starting)
- [ ] Days 15–21: Cold outreach begins — 20 contacts/day, signal-based
- [ ] Days 18–21: Website live with Calendly embedded
- [ ] Days 22–28: Deliver GTM audit — on time or early
- [ ] Day 28: Delivery call + retainer pitch (send proposal same day)
- [ ] Days 28–35: Keep cold outreach running — 20/day no exceptions
- [ ] Days 36–45: Second client signed
- [ ] Days 40–45: Begin case study #1 (even preliminary results)

**GATE Day 45: If zero paid revenue, run the free audit test.**
Offer a free 2-hour GTM audit to 10 warm contacts. If 3+ say yes,
demand exists and price is the problem. If <3 say yes to free, the
offer needs rethinking.

---

## Phase 3 — Days 46–90: Scale to stability

**Goal:** 2–3 retainer clients. $10–15K CAD/mo. Delivery automated.

- [ ] Days 46–60: Third client in active proposal stage
- [ ] Days 55–70: Identify and test first subcontractor ($300–500 test project)
- [ ] Days 60–75: Publish case study #1 + begin case study #2
- [ ] Days 75–90: Raise rates on all new proposals ($6,500–7,000/mo)

**Day 90 worst-case target:** 2 retainer clients, $10–12K CAD/mo,
1 published case study, delivery automations running.

---

## Circuit breakers (pre-committed decisions)

| Trigger | Threshold | Mandatory action |
|---------|-----------|-----------------|
| Runway drops below 8 weeks | <8 weeks of expenses in savings | Start job search immediately, run both in parallel |
| Zero revenue at Day 45 | No paid engagement of any kind | Run free audit test. Diagnose offer vs. price vs. ICP. |
| Proposal close rate <15% | 3+ proposals sent, 0 closes | Stop sending proposals. Fix the underlying issue first. |
| Reply rate <3% | After 200 cold messages | Rewrite the outreach completely. Test 3 framings with 50 each. |
| Month 3 revenue <$5K | Three months in, under $5K/mo | Trigger vertical pivot — rebuild pitch around one specific industry. |
| Burnout symptoms | Dreading outreach + calls for 2+ weeks | Mandatory 3-day full stop. Then evaluate fit, not just execution. |
